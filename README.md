# image-uploader-multer-cloudinary
A simple Node.js + Express project that allows users to upload images using Multer (for handling multipart form data) and Cloudinary (for cloud image storage). The uploaded image URL is then displayed using EJS templates.

🚀 Features

Upload images directly from your computer

Store images in Cloudinary

Display uploaded image instantly on the page

Uses Multer middleware for local file handling

Uses MongoDB + Mongoose for storing image data

🛠️ Technologies Used

Node.js

Express.js

EJS

Multer

Cloudinary

MongoDB
